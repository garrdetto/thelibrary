# Data, bindings and secrets

Every D1 table, KV key and secret. Moved out of AGENTS.md so it loads only when this area is worked on; keep it current here, not in AGENTS.md.

- Cloudflare D1 `thelibrary-db` (binding `DB`); schema in `migrations/`. Tables: library_settings (admin library order), users, fairway_records (Fairway Nine record book), sessions, login_failures, tickets, pool_preferences, pool_practice_records, racing_profiles, racing_laps, module_scores, module_score_details (the word or other detail shown beside a module score), creations, lyric_corrections, lyric_presets, voice_designs (Voice Generator voices), park_saves_by_park (one save per park), darts_legs, darts_bests, darts_matches and darts_averages (Darts record book), park_migrations, park_saves and park_scores (older, no longer read), park_scores_by_park, park_scoreboard_resets, maplestreet_world (Fox Plains's shared world, written by its Durable Object), shorttrack_paint_requests (AI paint designer usage), shorttrack_handling (published Short Track handling per track), shorttrack_field_schemes (AI-designed field schemes), maplestreet_assets (admin-published Buy items and vehicles, and Short Track race cars as kind `stcar`, with drafts), maplestreet_items and maplestreet_vehicles (older copies, no longer written), meshy_jobs (Meshy tasks started from the admin editors), park_custom_rides (Thrill Park Ride creator), angler_profiles, angler_sessions and angler_catches (Northwoods Angler), rackreel_profiles (Rack & Reel cash, owned gear, loadout and tasks), rackreel_records (Rack & Reel high scores, top three per category), rackreel_lobbies (Rack & Reel open lobbies), arena_duel_stats and arena_duel_runs (Vector Arena 1v1 Duel record book), bushleague_ratings and bushleague_matches (Bush League Baseball ranked ladder and results), hood_lots (The Hood households: lot state, public shell, presence), hood_requests (The Hood service calls), songmaker_songs (Song Maker songs), music_tracks (site music player), sunvault_profiles (Sun Vault balances, streaks and open rounds; also the wallet Beanstalk Bounty spends), beanstalk_profiles (Beanstalk Bounty machine state and open rounds), modollaz_profiles (Mo' Dollaz meters and stats; its balance is the vault wallet in sunvault_profiles), clipart_jobs (clipart generator jobs), score_notices (top-3 knocked-out notices), world_edit_revisions and world_edit_state (Life Sim World Editor revisions and the draft and published pointers), gspro_sessions, gspro_shots, gspro_bridge, gspro_rounds, gspro_course_shots and gspro_settings (GSPro Analyzer), site_changes, site_change_settings.
- Workers KV `thelibrary-files` (binding `FILES`) for binary files: `cue/<userId>`, `skin/<userId>/<asset>`, `image/<userId>/<creationId>`, `maplestreet-item/<itemId>`, `maplestreet-vehicle/<vehicleId>` (and `/wheel`), `shorttrack-car/<carId>`, `meshy-model/<jobId>`, `park-ride/<rideId>/mesh|thumb|source`, `song/<userId>/<songId>`, `music/<trackId>`, `clipart/<jobId>` (clipart generator results, 30-day TTL), `world-edits/<world>/<revisionId>` (World Editor revisions, JSON).
- Secrets: `ADMIN_PASSWORD`, `ANTHROPIC_API_KEY` (Short Track paint designer), `GEMINI_API_KEY` (studios and the rest of the site's AI), optional `ELEVENLABS_API_KEY` (Voice Generator), optional `MESHY_API_KEY` (Meshy panel), and the site-changes secrets above. Bindings: `AI` (Workers AI, the clipart generator's free engines; it only reaches Cloudflare, so `pnpm dev` leaves it off unless started with `TL_REMOTE_BINDINGS=1` and a Cloudflare login or `CLOUDFLARE_API_TOKEN`, through `remoteBindings` in `vite.config.ts`). Config in `wrangler.jsonc`.
- `.github/workflows/sync-worker-secrets.yml` copies `ANTHROPIC_API_KEY`, `GEMINI_API_KEY` and `ELEVENLABS_API_KEY` from the repository secrets onto the Worker with `wrangler secret put` (skipping any that aren't set, never blanking one; it fails if `ANTHROPIC_API_KEY` is missing). It runs when the file changes on `main` and from the Actions tab, so a key added or rotated in GitHub reaches the studios by re-running it.
