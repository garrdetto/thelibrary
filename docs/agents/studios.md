# Studios (AI chat, Image, Lyric, Voice)

Server code for the studios. The studio rules themselves are in AGENTS.md. Moved out of AGENTS.md so it loads only when this area is worked on; keep it current here, not in AGENTS.md.

- `src/server/routes/studio.ts` + `src/server/lyrics.ts`: `/api/studio`, `/api/library?id=` (version history only), `/api/asset`, `/api/learning`, `/api/lyric-presets`.
- `src/server/claude.ts`: Claude Messages API client (plain `fetch`, prompt caching on system prompts, tool output, web search) from the `ANTHROPIC_API_KEY` secret. Only the Short Track paint designer uses it now. Opus 5.5 rejects a forced `tool_choice`, so `forceTool` sends `tool_choice: auto` plus a system line telling the model to answer only through that tool; `effort` sets `output_config.effort` and adds 24,000 `max_tokens` for thinking. Every request opts into server-side refusal fallback (`anthropic-beta: server-side-fallback-2026-07-01`, `fallbacks: "default"`). Provider errors are logged and mapped to plain messages.
- `src/server/code-guard.ts`: the studios' no-code rule. `NO_CODE_RULE` goes into every studio system prompt, `looksLikeCode` checks every studio input (prompt, saved instructions, custom genre, artist, manual edits) and every model output, and `NO_CODE_MESSAGE` holds the refusal shown for each studio. AI chat is the exception: it answers any topic and uses `CHAT_CODE_RULE` instead (no writing programs or scripts, but browser help, DevTools, console/network errors and inspecting or live-editing elements are allowed with short snippets); its prompt skips `looksLikeCode` and its answer is checked with the looser `looksLikeProgram`.
- `src/server/gemini.ts`: Gemini client from the `GEMINI_API_KEY` secret (the studios through `src/server/studio-ai.ts`, Song Maker, cue art, car skins, vehicle suggestions). It connects to Google AI Studio or, for Vertex AI keys, to Vertex AI in express mode (`vertexai: true`, global endpoint `aiplatform.googleapis.com`): `geminiBackend` picks Vertex for keys starting with `AQ.` unless the optional plain Worker variable `GEMINI_BACKEND` is set to `vertex` or `studio`. Song Maker's Lyria songs call the AI Studio `interactions` endpoint directly and need an AI Studio key.
- `src/server/studio-ai.ts`: the studios' AI client on Gemini (`GEMINI_API_KEY`, `STUDIO_TEXT_MODEL` = `TEXT_MODEL` `gemini-3-flash-preview`). `askStudio` takes a system prompt, chat history (text and image blocks), an optional JSON schema (`responseJsonSchema`, read back as `data`), optional Google Search grounding and, for explicit lyrics, `BLOCK_ONLY_HIGH` safety thresholds; a blocked reply comes back as `refused`. AI Chat, the Lyric Studio (songs, the Suno style prompt, artist/genre research with search, then without) and the Image Studio's art director use it; the Image Studio then draws with `IMAGE_MODEL` (`gemini-3.1-flash-image`), sending the source picture for edits. When Gemini returns no picture or fails (a free-tier key has no image quota), `src/server/studio-image.ts` draws it instead with FLUX.2 klein 9B on the free Workers AI `AI` binding (source picture as `input_image_0` for edits, retried from the text alone if that fails). `geminiFailure` maps provider errors to plain messages. `src/server/svg-art.ts` only keeps the MIME type and sandbox CSP for older SVG pictures from the brief Claude-drawn period; editing one sends its description instead of the picture.
- `src/server/routes/voice.ts` + `src/server/elevenlabs.ts`: `/api/voice`, the Voice Generator (studio page `voice`). Calls ElevenLabs with the `ELEVENLABS_API_KEY` Worker secret (never sent to the browser; ElevenLabs errors are logged and mapped to plain messages). GET returns `configured`, the user's saved voices from D1 `voice_designs` (migration 0034, also created on first use: who designed which ElevenLabs `voice_id`) and, for administrators, the other non-premade voices in the ElevenLabs account. POST (same-origin, Zod, `looksLikeCode` refused): `design` (Voice Design `/v1/text-to-voice/design`: description 20–1000 characters, optional preview text 100–1000 or auto-generated, design model `eleven_multilingual_ttv_v2` or `eleven_ttv_v3`, loudness, guidance, enhance; returns up to three base64 MP3 previews), `remix` (`/v1/text-to-voice/<voiceId>/remix` with a description of the change), `save` (`/v1/text-to-voice` from a preview's `generated_voice_id`; `replaceVoiceId` deletes the remixed original afterwards), `edit` (name and description through `/v1/voices/<id>/edit`), `speak` (text-to-speech of the user's own text, up to 2,500 characters, model `eleven_multilingual_v2`, `eleven_v4` or `eleven_flash_v2_5`, stability/similarity/style/speed; returns `audio/mpeg`, not stored) and `delete` (removes the voice from ElevenLabs and D1). Users act only on voices they designed; administrators can act on any voice in the account. The page is `src/components/VoiceStudio.tsx`.
- `src/lib/studio-types.ts`: browser-safe studio types.
