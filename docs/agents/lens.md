# Lens Creator

The face-lens editor (React view). Moved out of AGENTS.md so it loads only when this area is worked on; keep it current here, not in AGENTS.md.

- Lens Creator (`#lens`, module id `lens`, a React view like Thrill Park, not an iframe): a face-lens editor that runs live on the camera or on an uploaded photo, entirely in the browser (nothing is uploaded or stored; lenses are saved and opened as `.lens.json` files, snapshots as PNG, clips as WebM/MP4 via `MediaRecorder`). `src/components/LensCreator.tsx` is the UI (Hair, Face, Makeup, Extras, Filter tabs, starter presets, randomiser). `src/lib/lens-types.ts` holds the Zod `lensSettingsSchema`, option lists and presets; `src/lib/lens-tracking.ts` loads MediaPipe Tasks Vision (`@mediapipe/tasks-vision` 0.10.14 module and wasm from jsDelivr, face landmarker and hair segmenter models from Google's model storage) at runtime only when the page opens, with GPU then CPU delegates; `src/lib/lens-geometry.ts` has the landmark indices, the face frame (forehead origin, eye-line axes, face-width unit) and builds up to 10 warps (bulge or shift with a smooth falloff) whose inverse is applied to landmarks so drawn overlays stay on the warped face; `src/lib/lens-renderer.ts` is one WebGL pass (warps, edge-aware skin smoothing inside a face mask, real-hair dye from the segmentation mask, colour filters, vignette, grain); `src/lib/lens-overlays.ts` draws the hairstyles (back hair with the face oval cut out, then the fringe), makeup, eyewear, headwear and animated effects on a 2D canvas in face units.
