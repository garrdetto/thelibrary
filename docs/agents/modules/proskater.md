# Pro Skater AI

three.js skateboarding module. Moved out of AGENTS.md so it loads only when this area is worked on; keep it current here, not in AGENTS.md.

- Pro Skater AI (`modules-src/proskater/`, module id `proskater`) is a three.js (bundled 0.186.1, `WebGLRenderer`) skateboarding module whose whole engine is one inline module script in `modules-src/proskater/index.html` (`index.ts` only exists so `vite.modules.ts` finds it), split into numbered sections: `CONFIG`, scratch vectors, `SaveStore`, `Profiles`, content (`DECKS`, `PARKS`, `CHAPTERS`, `MODES`, `QUALITY`), procedural PBR `Textures`, `ResourceScope` + `Unloader`, `Park`, letters, `SkaterRig`, `Input`, `Tricks`, `Skater`, `Session`, `Sfx`, `Hud`, `Level`, `UI`, `App`. Parks are analytic: `Park.heightAt` is the max of each element's local profile (`halfpipe`, `quarter`, `funbox`, `kicker`, `ledge`, `rail`) and the meshes are built from the same profiles; `Park.gradient` takes the gentler one-sided slope at creases so ledge sides read as walls. Ground motion is a particle on that height field (`a = −(g + κv²)∇h / (1 + |∇h|²)`), takeoffs happen when the surface falls away faster than gravity, and launches off steep transitions turn outward speed into vertical (vert airs come back into the pipe). Four modes: Story (three chapters, one per park, objectives pay cash and unlock the next park and a deck; the S-K-A-T-E letters are extruded shapes collected by a distance check then `Box3`∩sphere), Timed Blitz (60 s, best per park), Half-Pipe Showdown (60 s, ×2 for tricks started inside the `HALF_PIPE_ZONE` box) and Free Skate. Progress is kept in the browser on purpose (the owner asked for no backend): IndexedDB database `proskater-ai`, store `profiles`, one record per library username (`user:<name>`, read from `/api/pool-account`) or `guest`, with localStorage and memory fallbacks; Reset Profile deletes the record and the database when it was the last one. Leaving a level runs `Unloader.purge`, which disposes every geometry, material, texture slot, skeleton and shadow map recursively plus anything the level's `ResourceScope` tracked; only the PMREM environment map persists. `window.__skater` exposes the app for checks. Optional authored scenery is listed in `ASSET_MANIFEST` (loaded with `GLTFLoader`, never used for collision). The rider is the only Meshy asset: an original correctional-officer skater (`assets-src/proskater/skater-meshy.glb`, Meshy-generated and rigged) dressed in Blender by `modules-src/proskater/tools/build-models.py` (black beanie with a blue shield patch, the patch on the left sleeve and a flag on the right, two chevrons for Officer, yellow SKATE on the left pocket flap; decals from `tools/decals.mjs`), which also models the board and writes the Sergeant (three chevrons) texture `public/modules/proskater/skater-sergeant.webp`; rerun it and `pnpm assets` after changing either. Rank is a profile setting (Options or the title-screen Rank button). In game the rider's bones copy the hidden procedural rig every frame, so physics, IK and tricks are unchanged; `?models=0` keeps the procedural rider. The starter park (`warehouse` id, shown as Cell Block Yard) is a prison rec yard (`theme: 'prison'`). Trick names follow the owner's list (Chowhall Chop, Shakedown Shuvit, Solitary Spinner, Seg-Session, The Meat-Log Manual, The Write-Up Wallride, The Major Misconduct, and the specials The K2 Crashout, The Suit-Up Slam with W, The Icebox Invert with S). On-screen keys (`#osd`, H toggles) show every key with its letter and also work as touch or mouse controls. Leaderboards: each mode has its own board (`proskater-story`, `proskater-blitz`, `proskater-showdown`, and `proskater-free` for the biggest Free Skate combo), saved live with `tlScores.progress` and finalized when the clock ends or the run is left; the page shows them as tabs (`scoreBoardGroups` in `src/lib/module-scores.ts`, `src/components/ModuleScoreTabs.tsx`).
