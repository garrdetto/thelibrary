# Music player and radio

The site ribbon music player. Moved out of AGENTS.md so it loads only when this area is worked on; keep it current here, not in AGENTS.md.

- `src/server/routes/music.ts`: `/api/music`, the site-wide music player. Tracks are D1 `music_tracks` rows (migration 0043, also created on first use; `position` is the playlist order) with the MP3 in KV `music/<id>` (≤ 24 MB, checked for an ID3 tag or MPEG frame sync). GET returns the signed-in account's playlist (`enabled` only with the `music` grant; `music:<trackId>` grants narrow it to those tracks, none means every track); `?file=<id>` streams one track with byte ranges to the admin or a listener who has it; `?admin=1` (admin) lists every track and listener. POST (admin, multipart `file`, `title`, `artist`, `duration`) uploads, PATCH (admin) `rename`/`order`, DELETE `{id}` (admin) removes the track and strips its `music:<id>` grants. The player is `src/components/music/MusicPlayer.tsx`, part of the site ribbon (`src/components/ribbon/SiteRibbon.tsx`): a bar fixed to the bottom of every page, mounted once in `src/routes/__root.tsx` so playback keeps going across views and routes. The ribbon holds the Axiom Radar link (start slot), the player, and the group chat (end slot); `index.tsx` portals the Radar link and `GroupChat` into the slots with `RibbonSlot`. It shows only when it has a visible `.ribbon-item`, and then sets `--tl-ribbon-h` (42px) on the root: `body` gets that bottom padding, `.sidebar` stops above it, and full-height layouts subtract it (`calc(100dvh - var(--tl-ribbon-h,0px) - …)`), so use that variable in new full-height CSS. The player's station list or playlist and the chat panel pop up above the bar, and each closes on a click anywhere else (module iframes included). The player remembers track, position, volume, shuffle and paused state in `localStorage` (`tl-music`) to resume after a full page load, starts on the first click when the browser blocks autoplay, pauses other tabs through a `BroadcastChannel`, and refetches on focus or the `tl-access-changed` window event. The player also has a Radio source (the only source when no tracks are assigned): `src/lib/radio-stations.ts` lists 57 Wisconsin stations (Milwaukee, Madison, Green Bay & Fox Valley, WPR statewide, around the state) with direct HTTPS MP3/AAC stream URLs that a plain `<audio>` tag can play (iHeart `stream.revma.ihrhls.com/zc<id>`, Triton `playerservices.streamtheworld.com/api/livestream-redirect/<mount>`, Amperwave `live.amperwave.net/direct/<mount>`, station Icecast servers; never HLS `.m3u8` or http URLs, which Chrome or HTTPS block). `src/components/music/RadioPicker.tsx` is the searchable station popup. Live streams re-tune on resume instead of playing stale buffer and retry twice on a dropout. When a station changes its stream, find the new URL in iHeart's directory (`us.api.iheart.com/api/v2/content/liveStations?callLetters=<CALL>-FM`) or radio-browser.info and check it returns audio over HTTPS. The admin side is `src/components/admin/MusicLibrary.tsx` (`#admin/music`). Shared helpers: `src/lib/music.ts`.
